# POS-013 — Deployment fullstack dan panduan portfolio

Status: Dalam pengerjaan — konfigurasi siap; menunggu login Render dan verifikasi live
Prioritas: P1
Dependensi: POS-012

## Tujuan

Siapkan deployment Node.js yang menyajikan build React dan Express pada Render Free.
Pemilik memilih hosting gratis dan menerima SQLite sementara yang dapat direset saat
sleep/restart/deploy ulang. Persyaratan disk persisten dan backup lintas restart dari
rencana awal diganti sesuai keputusan ini; tidak membuat layanan berbayar.

## Kriteria penerimaan

- [ ] URL live satu origin melayani React dan API; HOST/PORT/NODE_ENV sesuai hosting.
- [x] Render Free tanpa disk berbayar dikonfigurasi; batas data sementara dan ketiadaan backup dijelaskan.
- [ ] Cookie Secure, HTTPS, trust proxy dan origin diverifikasi pada Render live.
- [x] Healthcheck/lint/build/CI tanpa unit test disiapkan dan didokumentasikan.
- [ ] Build/deploy di Render dan workflow GitHub Actions benar-benar lolos.
- [ ] Saat file database direset hosting, sesi lama kembali ke masuk dan login baru membuat contoh; diverifikasi live.
- [x] Pemilik memilih Render Free dan menerima data sementara; tidak membuat deployment berbayar.
- [x] Hosting Sites prototype dipertahankan; backend belum diklaim live.
- [ ] README memuat URL yang benar-benar diverifikasi, demo akses, dan petunjuk presentasi.

## Verifikasi tanpa unit test

1. Build, start mode production, dan buka semua route langsung.
2. Deploy ke Render Free; periksa health, sesi, checkout, HTTPS, isolasi dan pemulihan setelah data direset.
3. Jika target belum tersedia, catat status blocked/deployment belum selesai tanpa mengklaim live.

## Implementasi yang disiapkan

- `render.yaml`: satu Node Web Service Free, Singapore, branch main, Node 22.20.0,
  HOST 0.0.0.0, port dari Render, TRUST_PROXY 1, SQLite sementara, health `/api/health`.
- Build `npm ci --include=dev && npm run check`, start `npm start`.
- `npm run render:login`, `npm run deploy:render -- --create` untuk service pertama,
  dan `RENDER_SERVICE_ID=... npm run deploy:render` untuk redeploy.
- `.github/workflows/check.yml`: check pada push main/PR tanpa unit test.
- Catatan data sementara pada halaman masuk saat build dengan
  `VITE_DEMO_EPHEMERAL_STORAGE=true`.
- README, PRD dan `docs/DEPLOYMENT.md`: persiapan akun/GitHub, dua pilihan deploy,
  data sementara, pemanasan sebelum presentasi, dan checklist live.
