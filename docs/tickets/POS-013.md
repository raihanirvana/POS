# POS-013 — Deployment fullstack dan panduan portfolio

Status: Belum dimulai
Prioritas: P1
Dependensi: POS-012

## Tujuan

Siapkan deployment Node.js yang menyajikan build React dan Express dengan disk persisten untuk SQLite.

## Kriteria penerimaan

- [ ] Satu origin melayani React dan API; HOST/PORT/NODE_ENV dikonfigurasi sesuai hosting.
- [ ] SQLite tersimpan pada volume persisten; tersedia prosedur backup/restore dan batas demo.
- [ ] Cookie Secure, HTTPS, trust proxy yang tepat, dan environment diatur.
- [ ] Healthcheck/lint/build/CI tanpa unit test terdokumentasi; restart tidak menghapus data.
- [ ] Keputusan hosting dikonfirmasi dari layanan yang tersedia; deployment berbayar tidak dibuat tanpa instruksi.
- [ ] Hosting Sites prototype dipertahankan sampai fullstack siap; Express/SQLite tidak diklaim berjalan di hosting statis.
- [ ] README memuat URL yang benar-benar diverifikasi, demo akses, dan petunjuk presentasi.

## Verifikasi tanpa unit test

1. Build, start mode production, dan buka semua route langsung.
2. Deploy ke target yang dipilih; periksa health, sesi, checkout, restart, persistensi, dan akses HTTPS.
3. Jika target belum tersedia, catat status blocked/deployment belum selesai tanpa mengklaim live.

## Bukti selesai

Belum tersedia. Isi perintah, hasil, dan keterbatasan yang benar-benar diperiksa saat tiket diselesaikan.
