# POS-010 — Dashboard dan laporan penjualan

Status: Belum dimulai
Prioritas: P1
Dependensi: POS-005, POS-006

## Tujuan

Agregasi server untuk dashboard, laporan periode, produk terlaris, dan CSV.

## Kriteria penerimaan

- [ ] Endpoint /api/dashboard, /api/reports dan ekspor menghitung data workspace di server.
- [ ] Tanggal hari ini dan batas periode inklusif memakai Asia/Jakarta.
- [ ] Nilai pendapatan setelah diskon, rata-rata transaksi, unit terjual, stok menipis, dan grafik konsisten.
- [ ] Laporan tidak mengklaim laba; rentang tanggal invalid ditolak.
- [ ] CSV sesuai periode, aman dari formula injection, serta berbahasa Indonesia.

## Verifikasi tanpa unit test

1. Bandingkan transaksi contoh dengan total dashboard/laporan.
2. Coba batas tanggal, hasil kosong, rentang invalid, dan unduh CSV.

## Bukti selesai

Belum tersedia. Isi perintah, hasil, dan keterbatasan yang benar-benar diperiksa saat tiket diselesaikan.
