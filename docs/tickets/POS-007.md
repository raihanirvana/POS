# POS-007 — Halaman produk React

Status: Belum dimulai
Prioritas: P1
Dependensi: POS-004, POS-006

## Tujuan

Hubungkan tabel produk, form tambah/edit, konfirmasi hapus, dan stok ke API.

## Kriteria penerimaan

- [ ] Pemilik dapat mengelola menu; kasir tidak diberi kontrol pengelolaan.
- [ ] Form punya label, validasi, loading, error server, dan konfirmasi hapus.
- [ ] Data berasal dari API dan bertahan saat halaman dimuat ulang.
- [ ] Nama/deskripsi ditampilkan aman sebagai teks; foto preset lokal digunakan.

## Verifikasi tanpa unit test

1. Tambah/edit/hapus via browser; refresh dan cek hasil di API.
2. Coba stok nol, masukan markup, dan API gagal; form menampilkan pesan yang membantu.

## Bukti selesai

Belum tersedia. Isi perintah, hasil, dan keterbatasan yang benar-benar diperiksa saat tiket diselesaikan.
