# POS-001 — Fondasi proyek dan aturan kualitas

Status: Selesai
Prioritas: P0
Dependensi: Tidak ada

## Tujuan

React + Vite, Express, koneksi SQLite, konfigurasi ESLint/Prettier, env, dan perintah menjalankan proyek.

## Kriteria penerimaan

- [x] Struktur client/ dan server/ terpisah; dependency terkunci dalam package-lock.json.
- [x] Satu npm run dev menjalankan frontend dan API dengan proxy /api.
- [x] GET /api/health benar-benar memeriksa koneksi SQLite dan frontend menampilkan hasilnya.
- [x] Fungsi maksimal 25 baris termasuk blank/comment/JSX; inline disable tidak diizinkan.
- [x] npm run check lolos; tidak ada unit test; database/env tidak masuk Git.
- [x] Prototype HTML bisa dibuka lewat /prototype/index.html; output React tidak menimpa dist/.

## Verifikasi tanpa unit test

1. Jalankan npm run check.
2. Jalankan npm run dev dan akses frontend; pastikan status backend terhubung.
3. Curl /api/health serta endpoint API yang tidak tersedia (404 JSON).
4. Build frontend lalu jalankan npm start; periksa frontend, API, dan prototype.
5. Buktikan fungsi 26 baris ditolak ESLint melalui snippet stdin sementara.

## Bukti selesai

Verifikasi selesai pada 14 Oktober 2026:

- `npm run check`: ESLint 10, format Prettier, dan build Vite lolos.
- `npm ls --depth=0`: dependency terpasang tanpa invalid peer; package-lock.json tersedia.
- Pemeriksaan ESLint melalui stdin: 25 baris diterima, 26 baris ditolak, inline disable tidak menghilangkan error. Tidak ada fixture atau unit test yang ditambahkan.
- `WEB_PORT=5174 npm run dev`: frontend dan API berjalan. Port 5173 sedang digunakan aplikasi lain, jadi verifikasi memakai 5174 tanpa menghentikan proses lain.
- HTTP/API smoke: health 200 dengan database connected, endpoint tidak dikenal 404, JSON invalid 400, payload lebih dari 100 KB 413; X-Request-Id tersedia.
- Google Chrome melalui Playwright: React menampilkan koneksi backend yang berhasil; prototype membuka 9 menu; tidak ada pageerror; halaman fondasi tidak overflow pada 360/768/1280px.
- `NODE_ENV=production npm start` sesudah build: Express menyajikan build React, API health, dan prototype pada origin yang sama; semuanya diperiksa di Chrome.
- `git check-ignore`: data SQLite, .env, node_modules, serta client/dist diabaikan. Prototype dist/ tidak dimodifikasi.
- `git diff --check`: lolos.

Batas tahap ini: hanya health API dan halaman fondasi. Skema/seed domain, sesi/peran, serta fitur POS fullstack belum diimplementasikan. Tidak ada deployment backend pada link Sites. Hosting dan fitur tersebut mengikuti tiket berikutnya.
