# POS-011 — Pengaturan kedai dan reset ruang demo

Status: Belum dimulai
Prioritas: P1
Dependensi: POS-007, POS-009, POS-010

## Tujuan

Pengaturan toko lewat API pemilik dan reset yang hanya memengaruhi ruang demo pengunjung.

## Kriteria penerimaan

- [ ] Nama/alamat/pesan struk divalidasi dan disimpan per workspace.
- [ ] Reset memerlukan konfirmasi serta berjalan atomik pada workspace terkait.
- [ ] Reset membatalkan keranjang di frontend dan mengembalikan seed; workspace lain tidak berubah.
- [ ] Struk yang sudah tersimpan memakai snapshot pengaturan saat penjualan.
- [ ] Kasir tidak bisa mengubah pengaturan/reset lewat API.

## Verifikasi tanpa unit test

1. Ubah pengaturan, buat transaksi, ubah lagi, dan periksa struk.
2. Reset di browser A; data browser B tetap utuh; uji pembatasan kasir.
