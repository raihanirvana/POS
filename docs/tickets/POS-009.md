# POS-009 — Struk dan riwayat transaksi

Status: Belum dimulai
Prioritas: P1
Dependensi: POS-008

## Tujuan

Struk menggunakan snapshot transaksi API, cetak browser, pencarian dan filter riwayat.

## Kriteria penerimaan

- [ ] Struk menampilkan nomor/waktu Jakarta, toko, pelanggan, item, diskon, metode, dan kembalian.
- [ ] Struk lama tetap sama setelah nama/harga produk atau pengaturan toko diubah.
- [ ] Riwayat mendukung tanggal, pencarian dan pagination; detail tidak bocor antar workspace.
- [ ] Cetak hanya area struk; dialog accessible dan dapat ditutup dengan Escape.

## Verifikasi tanpa unit test

1. Coba buka/cetak struk baru dan lama; lihat print preview.
2. Edit produk lalu buka struk lama; filter dan halaman riwayat diperiksa.

Belum tersedia. Isi perintah, hasil, dan keterbatasan yang benar-benar diperiksa saat tiket diselesaikan.
